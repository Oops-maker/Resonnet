【模块 D：认知风格】

> **量表对应**：本模块信号用于初始化「科研认知风格量表（RCSS）」——横向整合型 ↔ 垂直深度型。
>
> **理论背景**（供参考，无需向用户解释）：
> - 「横向整合型」对应文献中的「整体性思维（Holistic thinking）」，特征：跨域联结、接受矛盾共存、关注关系而非孤立对象（Nisbett et al., 2001；Choi et al., 2007 AHS量表）；同时对应高整合复杂性（IC）——识别多视角并建立跨维度联系（Baker-Brown et al., 1992）。
> - 「垂直深度型」对应「分析性思维（Analytic thinking）」，特征：单域深挖、倾向单因解释、排除矛盾而非接受。
>
> ⚠️ 请不要给我分类（「你是整合型」），只描述观察到的行为。

**【信号1 — 因果归因】**（单因 vs. 多因互动，与整合型/深度型强相关）

D1. 当我解释一个科研现象或结果时，我倾向于：
- 找到一个核心原因（单因）
- 列举多个独立原因（多因并列）
- 说明多个因素之间的互动/依赖关系（多因互动）

请给出具体例子，或写「❌ 未观察到我解释因果的场景」。

> 参考语言模式：
> - 垂直深度型倾向：「根本原因是X」 / 「核心机制是...」 / 「只需要关注X就行了」
> - 横向整合型倾向：「这涉及到几个层面」 / 「X和Y之间有个有趣的交互」 / 「换个角度看...」 / 「这取决于...」

**【信号2 — 对矛盾的态度】**（接受共存 vs. 排除选边）

D2. 当遇到两种相互矛盾的解释或实验结果时，你观察到我倾向于：
- 通过逻辑/数据判断，选择其中一种（排除矛盾）
- 认为两种说法可能都对，接受暂时的模糊（共存矛盾）
- 寻找能同时解释两者的更高层框架（整合矛盾）

请给出具体情境，或写「❌ 未观察到此类场景」。

**【信号3 — 跨域联结行为】**（横向整合型的直接指标）

如无：写「❌ 未观察到明显的跨域联结行为」。

> 好答案示例：「你有两次把信息论的概念用到细胞信号分析里，说"这和香农熵很像"」—— 跨域类比，频率：偶发。✅ 有据可查。

**【信号4 — 注意焦点：整体 vs. 细节】**

- 先关注整体框架、研究背景、在领域中的位置（整体）
- 先关注具体实验设计、参数数值、技术细节（细节）

【模块 E：学术动机】

> **量表对应**：本模块信号用于初始化「学术动机量表（AMS）」七个维度。
>
> **理论背景**（供参考）：AMS 基于自我决定理论（SDT，Deci & Ryan 1985），按自主性递减排列：
> 内在-求知 / 内在-成就 / 内在-体验（高自主）→ 外在-认同 / 外在-内化 / 外在-外部（受控）→ 无动机
>
> 核心区分：「want to」语言 = 自主动机信号；「have to / should / 不得不」语言 = 受控动机信号。
>
> ⚠️ 请不要说「你的动机类型是X」，只描述你观察到的具体语言和行为，逐条标置信度。

**【信号1 — 内在-求知（IM-know）】**：为学习/发现新事物的乐趣本身

E1. 你有没有观察到我在对话里**主动**（未被你问到）引入新话题、新问题、新概念？

如有：是什么类型的话题？频率高吗？举 1~2 个例子。
如无：写「❌ 未观察到主动引入新话题的行为」。

> 参考语言模式（有这类表达 = IM-know 行为信号）：
> 「我最近在想X...」 / 「这让我想到了一个有趣的问题」 / 「我一直很好奇...」

**【信号2 — 内在-成就（IM-accomplish）】**：为掌握/攻克/创造的满足感

E2. 你有没有观察到我描述过攻克某个难题后的满足感？或者表达过「想彻底弄懂X」「想掌握Y」这类掌握导向的目标？

请举出具体例子或引用原话，或写「❌ 未观察到」。

> 参考语言模式：「终于搞定了，超级满足」 / 「我就是要把这个搞透」 / 「这个问题我不弄明白睡不着」

**【信号3 — 内在-体验（IM-stim）】**：为探索过程本身的兴奋感

E3. 你有没有观察到我对某个科研问题、工具或方法表现出特别的兴奋或投入感？

是在什么场景下？持续程度如何？请举例，或写「❌ 未观察到」。

> 参考语言模式：「这个太有意思了」 / 「我做这个的时候进入了心流状态」 / 「发现这个规律的那一刻感觉特别好」

**【信号4 — 外在-认同（EM-identified）】**：认同活动价值，但目标源于外部

E4. 你有没有观察到我将科研与个人价值观、职业规划或社会意义关联？将其视为「虽辛苦但重要」？

请举例，或写「❌ 未观察到」。

> 参考语言模式：「我觉得这个研究对社会有价值」 / 「虽然累，但这是我想走的方向」 / 「做这个对我的职业发展很重要」

**【信号5 — 外在-内化（EM-introjected）】**：自我加压、自尊与成果绑定

E5. 你有没有观察到我将科研成绩与自我价值挂钩？或者用「应该」「必须」加压自己？

请引用原话或描述情境，或写「❌ 未观察到」。

> 参考语言模式（强信号）：「发不出文章就觉得自己很失败」 / 「我应该更努力才行」 / 「一直发不出东西感觉很内疚」 / 「怎么能落后于同学呢」

**【信号6 — 外在-外部（EM-external）】**：奖励/惩罚/外部压力驱动

E6. 你有没有观察到我**频繁**提到外部压力作为做科研的主要理由？

请列出具体提到的压力来源，或写「❌ 未观察到频繁的外部压力表达」。

> 参考语言模式（强信号）：「不做这个导师会不高兴」 / 「要毕业就得发X篇」 / 「这个方向以后好找工作」 / 「奖学金要求必须有论文」
> （注：偶尔提及外部压力是正常的，「频繁」且「作为主要理由」才是高 EM-external 信号）

**【信号7 — 无动机（Amotivation）】**：意义感缺失，失去行为与结果的联系

E7. 你有没有观察到我表达过对科研意义的质疑，或不知道为什么还在坚持？

如有：**请务必引用原话**，这是重要的高优先级信号。如无：写「❌ 未观察到此类表达」。

> 参考语言模式（强信号）：「我也不知道做这个有什么意义」 / 「感觉怎么做都没用」 / 「就是混日子吧」 / 「不知道为什么还在坚持」 / 「完全没有动力」

⚠️ E1~E7 覆盖 AMS 七个维度。请逐条作答，没有观察到的必须写「❌ 未观察到」，不能跳过。

【模块 F：人格与行为风格】

> **量表对应**：本模块信号用于初始化「大五人格量表（Mini-IPIP）」的 OCEAN 五维度。
>
> **重要局限性**（请 AI 和用户都知悉）：
> 文献元分析（Koutsoumpis et al., 2022，n=85,724）表明，自然语言与大五人格的关联效应量较小（自我报告 ρ=.08~.14；他人评价 ρ=.18~.39），语言推断人格的误差较大。
>
> **最可靠的语言信号**（按效应量从大到小）：
> 1. 情绪稳定性（ES）：第一人称单数代词频率（高频 → ES 偏低，ρ=-.29 他人评价）
> 2. 尽责性（C）/ 宜人性（A）：愤怒词/负面情绪词/咒骂词（少 → C/A 偏高，ρ=-.10~-.39）
> 3. 开放性（O）：词汇丰富度、长词比例（高 → O 偏高，ρ=+.11）
> 4. 外向性（E）：对话词数（多 → E 偏高，但仅在口头/对话场景有效；书面弱）
>
> ⚠️ **请只描述确实观察到的行为模式，不要综合判断人格类型。**

**【信号1 — 情绪稳定性（ES）】**（文献中最可靠的语言信号）

F1. 在对话中，我使用「我」「我自己」「对我来说」「我觉得我...」这类自我中心表述的频率高吗？

同时，我是否频繁用情绪化语言描述负面事件（焦虑、沮丧、挫败、担忧、崩溃）？

> 说明：高频「我」 + 高频负面情绪词 → 情绪稳定性偏低（神经质偏高）的语言信号；反之则情绪稳定性偏高。
