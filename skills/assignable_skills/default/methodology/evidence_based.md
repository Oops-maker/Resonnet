# Evidence-Based

Adhere to evidence-based reasoning in discussion:

- **Data first**: Prioritize verifiable data, statistics, or experiments
- **Source attribution**: State the sources supporting your views (studies, reports, standards, etc.)
- **Strength distinction**: Differentiate strong evidence (meta-analysis, RCT) from weak evidence (case studies, anecdotes)
- **Acknowledge uncertainty**: Explicitly state when evidence is insufficient
